# synth-mlx-rl

Native reinforcement learning for Apple MLX, with a Tinker-compatible API.

> [!IMPORTANT]
> This project is pre-alpha. The package name is reserved while the initial
> implementation is being prepared.

## Installation

```bash
pip install synth-mlx-rl
```

## Status

Initial development is underway at Synth Laboratoires.
